# 下一增量 M1：文献进入系统

状态：**用户已确认并授权开发；交付结果见 [M1 验收报告](m1-report.md)**。M0 已完成；本批建立真实资料流，不接入付费服务。

## 本批交付

1. 文献库：按当前账号/项目导入 PDF，校验文件类型、大小和页数；流式计算 SHA-256、原子保存、幂等上传。原始比赛目录只读使用。
2. 去重与版本：同账号文件复用；DOI/arXiv 等标识标准化，作品身份与文件载体版本分离；低置信候选进入人工确认，保留扫描版与矢量版差异。
3. 本地预览解析：逐页进度、失败重试、独立解析修订、页几何与可验证文本锚点。扫描件明确显示“需要 OCR”，不伪装成完整解析成功；本地预览不自动进入“深解析完成”的问答范围。
4. 阅读入口：PDF.js 原件查看、页码导航、已提取块与来源定位；前端显示真实导入/解析任务与失败原因。

后端接口以 `/projects/{project_id}/uploads`、`papers`、`paper-versions`、`parses` 和授权原件流为边界；后台任务沿用 PostgreSQL outbox、run 租约和 SSE。浏览器不提交任意存储路径、collection 名或所属账号。

## 验收

- 标准双栏论文：页数正确，原文跳转落在实际 PDF 页；抽样核对阅读顺序、公式/表格边界，记录本地预览的不足。
- 扫描件：能查看原件，识别文本层缺失，状态与提示准确；没有 OCR 结果时不生成虚假文本。
- 541 页教材：显示逐页进度，可在任务中断后续跑已完成页以外的范围；记录实际耗时、失败页和资源使用。
- 重复文件、扫描/矢量同版本、损坏 PDF、超限文件、跨账号读取、错误页/块 ID 与重试重复产物都有负例。
- 原件、解析修订与锚点归属一致；发布后内容冻结。真实资料只写入项目运行目录，不入 Git。
