## 本轮已确认的架构决策

| 决策 | 提案 | 影响 |
|---|---|---|
| 系统组织 | 单仓库、模块化后端，API/worker/Beat 分开运行，同机部署 | 降低初期运维工作，保留职责边界 |
| 用户范围 | 个人空间 + 独立评审账号，数据隔离，首版无团队协作和公开注册 | 适合个人参赛与受控公网演示 |
| 证据基础 | 原件/论文版本/解析版本/结构块/产物版本分别标识 | 问答、翻译、引用与写作能追查同一原文 |
| Agent 控制 | 一个 LangGraph 主编排器，受控领域工具和有界子流程 | 减少重复规划与无界调用，便于测试和解释 |
| 任务恢复 | PostgreSQL 权威状态 + outbox + 幂等 worker + 远端回执 | 处理重启和重复投递，不承诺跨系统 exactly-once |
| 阅读翻译 | 原始 PDF + 对齐 HTML/Markdown 译文；按块联动 | 覆盖赛题允许的译文形式；首版不做原位译文 PDF |
| 科研计算 | 受控 Pandas/Matplotlib 模板、独立子进程、脚本与数据可复现 | 首版不执行任意生成代码，不引入完整持久 Python/R 内核 |
| OpenAI4S | 优先参考执行记录、证据和产物版本设计；具体代码复用单独记录 | 避免直接接入第二套主 Agent 引擎 |
| 交互与接口 | `/api/v1`、异步运行回执、可恢复 SSE、确切版本下载 | 前端可显示真实进度与来源，断线无需重提任务 |

详细行为、失败处理和接口边界见 [architecture.md](architecture.md)，测试场景见 [acceptance.md](acceptance.md)。
