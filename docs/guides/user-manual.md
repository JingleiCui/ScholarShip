# ScholarShip 完整使用手册

适用版本：2026-11-18 工作区。本文对应已接入业务接口的顶部导航工作空间。品牌为 ScholarShip / 学者之舟，寓意“学海无涯，AI作舟”。界面和接口存在差异时，以当前代码与 API 文档为准。

第一次使用可先看[从第一篇 PDF 到研究成果](first-research-session.md)，对照高清演示按顺序操作；本文保留各模块的详细行为与故障处理。

## 先理解你在操作什么

ScholarShip 将文献、解析修订、检索证据、回答和写作产物放在同一研究空间。最短路径是：导入 PDF → 阅读原件 → 解析文本结构 → 选择文献 → 建立索引 → 问答 → 点开引用核对 → 整理来源摘要。图表是一条独立路径：上传 CSV → 选择字段与图形 → 导出图片、数据和脚本。

**导入成功不等于 OCR 成功，解析完成不等于索引完成，任务成功不等于科学结论正确。** 每一步都要看对应状态。

| 操作类型 | 能做什么 | 是否调用模型 |
|---|---|---|
| 本地功能 | PDF 导入、文本预览、文本层结构解析、图谱计算、受控图表、明确步骤的拓扑图 | 否 |
| 历史成果 | 阅读已保存的回答、翻译、摘要及原文锚点 | 否 |
| 离线契约验收 | 用合成响应验证索引、任务、引用等软件流程 | 否；结果不能用于科研 |
| 真实云端生成 | 使用所选供应商进行向量化、重排、问答、翻译与写作 | 是；需要配置和有效执行策略 |
| 公开元数据服务 | arXiv/Crossref 搜索、公开 PDF 下载、GitHub 链接核验 | 不调用大模型，但会联网 |

当前开发环境已关闭新的云端推理。历史真实成果仍能回看。模型 Key、配置组和执行权限是三件不同的事；不要反复提交被拒绝的云端任务。

## 1. 启动与登录

已有环境在项目目录运行：

```bash
.venv/bin/python doctor.py
.venv/bin/python dev.py
```

先启动 Docker Desktop。第一次安装按[安装指南](getting-started.md)运行 `bootstrap.py`，不要覆盖已有 `.env`。PyCharm 使用项目 `.venv/bin/python`，可运行 `dev.py` 或已有 ScholarShip All 配置。若已有项目启动器在运行，直接访问网页，不要重复启动。

- 本地页面：<http://127.0.0.1:15173>
- API 文档：<http://127.0.0.1:18080/docs>
- 完整容器模式页面：<http://127.0.0.1:18081>；与本地应用模式互斥。

使用 `researcher` 登录；密码在私有 `.env` 的 `INITIAL_USER_PASSWORD`。只在本地编辑器查看，录屏前关闭配置文件。`reviewer` 为隔离的只读账号，不共享研究账号的私人数据，也不能代替研究账号提交任务。

登录后查看页顶研究空间下拉框。**先选空间，再选文献。** 研究账号可点击页顶“新建研究空间”，填写名称并创建。新空间默认 mock 配置，适合练习；新克隆不会自带开发者数据。

验收：页顶显示当前空间；打开“文献库”能看到该空间的文献。若列表为空，先检查账号和空间，再检查是否真正导入过。

## 2. 首页与模型状态

顶部主导航为首页、文献库、阅读与问答、成果；“研究工具”完整列出六个命题模块，提供文献发现、引用图谱、写作与数据绘图入口。首页先给出四步路径，模型配置与运行检查独立放在设置。

进入“设置”可核对配置组、执行权限和预算状态。开发检查按需展开。“运行探针”只证明数据库、队列、向量库、后台任务等基础链路可用，不会回答科研问题。完整配置解释见[模型指南](models.md)。

不要在已有真实资料空间随意切换 embedding 配置并建立模拟索引：旧世代记录虽然保留，新活动指针可能影响当前使用。练习配置切换应在独立练习空间或隔离集成测试中进行。仅查看状态不改变配置。

## 3. 导入 PDF、管理版本

1. 进入“文献库”，检查空间。
2. 点击“导入 PDF”，选择一个或多个文件，单批最多 50 份。队列逐文件显示结果，可停止后续上传并重试失败项。追加当前作品版本时只选一份文件。
3. 等待“PDF 已导入本地，正在逐页生成预览”，在文献卡片中选择该文献。
4. 查看原始 PDF 与对应页文本。页码使用 PDF 文件页序，不一定等于印刷页码。
5. 通过解析修订选择框区分本地预览、本地文本结构和已发布的 OCR 结果。

相同字节文件再次导入，系统会提示复用原版本。文件改名不改变字节哈希。不同版本不是相同文件：系统可能提供疑似重复核验；“保留两份”和“拒绝本次候选”须根据页面文字处理，不能理解为任意删除历史文件。

若明确知道新文件属于当前作品：先选择原作品，勾选“将下次导入明确作为当前作品的新文件版本”，再导入新文件。完成后取消勾选，防止下一篇无关论文被错误关联。

展开“文献整理、版本比较与归档”：可改标题、设置当前首选版本、归档或恢复作品；选择另一版本后比较已解析文本。“检查正文／OCR 相似候选”比较前 3 页词组，并结合 PDF 正文提取的 arXiv 标识。v7/v1 会提供版本建议；相似度只是候选依据，不自动合并。差异展示是文本行比较，不是模型概括。

失败处理：上传被拒时查看大小／格式和提示；文件已成功但页面未更新时先刷新文献列表，不立即重复提交。同一内容可复用，不代表所有网络中断都没有生成记录。

## 4. 本地解析与扫描件

文本型 PDF：文献库选择文献 → “开始阅读” → “提取文本结构（本地）”；也可在“选词与双语翻译”中进入原本的本地结构解析。等待下方任务状态完成，再回到来源选择区勾选。该步骤使用本地文本层与启发式结构，不会上传 PDF。

扫描型 PDF：如果页面没有可提取文本，本地预览会显示需要 OCR；反复点击本地文本解析不能生成文字。当前页面没有面向任意文件的一键 MinerU 云端上传入口。已下载且获准的原生产物通过项目专用发布工具入库，之后可在文献库选择 OCR 修订。

恢复与重做的含义不同：对支持恢复的本地预览任务，继续失败页复用原修订；“新修订”产生新的解析结果。不要通过删库清空失败状态。任务中的“取消后续执行”可取消排队任务；运行中会等当前安全边界停止。已发出的模型请求先保留回执，未知状态仍需核对。任务显示“取消已请求”不代表供应商没有执行。

验收：检查前、中、后页面；至少核对一个章节、一处公式和一个表格。出现“ready”只是结构产物已就绪，不是这些内容全部识别正确。

## 5. 证据问答

问答位于“阅读与问答”中的“证据问答 / 多文对比”页签。从文献库点击“向这篇文献提问”会携带当前版本，不用重新寻找。展开问答来源可选择最多 8 个版本。公开元数据搜索独立位于研究工具的文献发现入口。

### 查看已经完成的真实回答

选择拥有成果的研究空间，向下找到“文献证据问答”及任务历史，展开已成功的问题。确认标签是模型真实响应或“原文结构提取／本地计算”，再点击回答旁的来源定位按钮。检查文件、版本、页码、引文与问题是否一致。旧错误答案有审阅警告，优先看已核对的新结果；警告不是删除错误记录。

### 在独立练习空间验证软件流程

1. 导入并完成一篇文本 PDF 的结构解析。
2. 确认使用离线验收方式，勾选文献（后端一次问答最多 8 个版本）。
3. 点击“建立所选文献索引”，等待成功。
4. 输入问题，点击“提交证据问答”。索引或模型配置不匹配时先解决提示，不连续点击。
5. 展开结果、点引用、刷新页面检查历史仍在。
6. 继续追问时使用页面的上一轮上下文入口，保持同一文献与索引范围；改变来源后应开启新会话。

模拟答案只验任务与引用契约，不可用它判断论文事实。如果没有独立练习空间，先只读回看已有成果，使用 `validate.py` 的隔离库完成模拟流程验证，不在真实空间覆盖活动索引。

### 新的真实问答需要什么

需要可用的 embedding、rerank、chat 服务，匹配的真实向量 profile 和索引，模型总开关以及覆盖当前项目、解析范围、角色、时间、额度的执行策略。当前额度已关闭；仅选择“真实云端”不能绕过准入。新的论文或重新提问需要重新确定执行范围，本文不恢复历史批次。

原文定位失败时先核对解析修订和文件是否仍在，不通过当前最新版替换旧引用。引用能打开也要检查它是否真正支持回答。

## 6. 阅读与翻译

文献库保留原始 PDF 排版；来源阅读器提供标题树和定位。对于能识别的参考文献，点击正文引用跳至 References，再使用返回定位回到原处；不同解析器的识别覆盖并不相同。

在“阅读与问答”选择恰好一个已解析来源，切换“选词与双语翻译”。“翻译所选整篇”创建全文任务；展开“选择页面与段落翻译”，输入 PDF 页码、勾选原文块，再点击“翻译勾选段落”。当前 UI 是块选择，不是已经完成的鼠标悬停翻译。

下方任务与产物展开后，使用“打开中英对照”（以实际按钮为准）查看已有翻译。默认逐块上下对照，可切换双栏同步；分别滚动并核对是否回到同一源块。代码、公式和部分标记由本地保留。

当前默认真实云端/历史回看，新任务按钮在没有有效准入时不可提交；明确选择离线契约验收才使用模拟响应，不能生成真实中文。真实旧译文可以回看，但必须人工校对术语、否定、数字和单位。发现语义错误时保留原结果并记录修订需求，不称“公式无损”就等于“翻译正确”。

在“目标语言”选择中文或 English。展开“选择页面与段落翻译”，勾选段落，或在原文框中选词／选句后点击“翻译选中文字”。公式和代码需完整选择。打开译文后，可在人工审阅区修改一段并填写依据；保存会生成新修订，原译文保留。在“已保存的翻译修订”可回看，支持双语 Markdown 导出。

## 7. 发现、订阅与反馈

1. 进入“研究工具”→“文献发现、追踪与推荐”，在“文献发现与追踪”选择 arXiv 或 Crossref。
2. 输入标题或主题，例如 `Attention Is All You Need`，点击“检索公开文献”。这会发送查询词；不是纯本地搜索。
3. 比对标题、作者、标识与年份。Crossref 只有元数据并不异常。
4. 仅在存在“下载公开 PDF 到文献库”时下载；没有该按钮不能猜测全文地址。
5. 对结果点“有用／不相关／取消反馈”。理由目前依据词语匹配与反馈，不是经过长期评测的个性化推荐模型。
6. “核验明确代码链接”检查元数据里明确给出的 GitHub 仓库，存在仓库不等于论文结果可复现。
7. 需要长期跟踪才点击“创建每日追踪”；它会由 Beat 持续调度，练习后点击“停止追踪”。不要为录屏创建后忘记关闭。

元数据服务独立于模型推理总开关。网络失败显示错误，不替换成虚构搜索结果；本机代理配置也不意味着该元数据客户端会继承系统代理。实际服务可用性需另行检验。

## 8. 图谱与研究方向

进入“研究工具”→“引用图谱、综述与研究方向”，在“图谱文献范围”逐项选择或“选择全部图谱文献”，点击“构建引用图谱”。同一作品不同版本会按作品去重。点击有证据的边查看来源；注意候选／已核验状态。

PageRank 反映当前选定网络中的连接结构。没有边时不得为了好看造边；只有两条候选边的图谱不支持“找到了整个领域的基石论文”。

研究方向是另一套来源选择：展开“研究方向的来源与执行方式”，选择解析来源，填写问题，例如“从注意力计算成本出发整理后续工作方向，区分原文结论与假设”。草稿在真实模式下会调用模型。

“后续研究检索词”仅发送显式填写的词到 arXiv。“检索后续证据”不调用模型但会联网，保存时间、范围和候选摘要。未找到匹配不等于证明方向无人研究。

## 9. 写作与来源整理

进入“研究工具”→“写作与可视化 Copilot”，选择已解析来源，填写 Idea，例如：“以长序列注意力的计算开销为动机，整理研究计划；不编造实验结果”。点击“生成带来源清单的框架”或“整理来源摘要”。当前未开放新云端时，先回看任务历史中的真实草稿。

展开结果，检查 Abstract、Introduction、Related Work、计划实验及 References。点击“查看来源笔记原文”，核对源块。下载“产物与来源清单”；部分旧稿有“下载整理版”，这是本地编辑派生，不应伪称新模型生成。

“整理摘要与原件 References”从已有产物生成新版本，保留原稿。扫描首页书目信息是自报告身份，不等于外部独立核验；有来源笔记也不等于每句话已证明。当前不是带多人协同编辑的完整论文编辑器。

## 10. CSV 图表与拓扑图

准备 UTF-8 CSV，首行字段唯一，不含空值、无穷值或非数值混入数值列。例如练习数据：

```csv
name,score,latency,year
A,72,120,2024
B,78,100,2025
C,81,95,2026
```

这些数字仅是教学数据，不是项目实验结果。进入“研究工具”→ 写作模块的“数据绘图”，选择 CSV；折线／柱状可设 X 为 `name`、数值列 `score`，单位 JSON 为 `{"score":"points"}`，点击“生成可复现图表”。散点图使用数值 X，例如 `year`。二维雷达用 `score,latency`；三维雷达还必须填写 `year`，明确不同单位的归一化及延迟越低越好的解释局限。

当前限制：CSV 不超过 2 MB、10,000 行、32 列。界面缺失值策略是拒绝。图注是数据统计描述，不自动证明显著性或因果关系。

下载 ZIP 后检查 `input.csv`、`chart.png`、`plot.py`、`metadata.json`、`README.txt`。在解压目录使用本项目 Python 运行 `plot.py`；不要改输入后仍声称重现原图。相同输入、配置、依赖和字体是重现条件；跨平台图片字节不保证一致。

拓扑示例填入：`输入 → 解析 → 检索 → 生成 → 证据核验`，点击“按描述生成架构图”。或展开精确编辑，节点每行一个，边为从 0 开始的 `起点,终点`。系统只按明确步骤连线，不运行任意模型生成 Python。

## 11. 常见问题和收尾

| 现象 | 优先核对 | 下一步 |
|---|---|---|
| 页面无法访问 | 当前是否本地模式、启动器和端口 | 读 `dev.py` 输出／运行 doctor，不杀陌生进程 |
| 登录失败 | 账号及私有密码、同源地址 | 使用同一页面 Origin；不要公开 Cookie |
| 文献不见了 | 当前账号、研究空间 | 切回正确空间，首次克隆本来没有旧数据 |
| 文献无法勾选 | 是否已有 ready 结构解析 | 在阅读页解析文本；扫描件需 OCR |
| 问答按钮不可用 | 索引、配置、来源模式 | 匹配配置；不要在真实空间随意重建模拟索引 |
| 409 云端未启用 | 执行策略和开关 | 这是准入拒绝，不代表 Key 一定错误 |
| 429 或 unknown | 供应商与调用审计 | 保留记录，停止新增请求，不自动重试 |
| 任务一直排队 | Worker、Beat、outbox 与依赖 | 查看项目日志，基础探针不能代替科研质量验收 |
| 图表生成失败 | 字段、空值、单位 JSON、字体 | 对照 CSV 修正；不用反复上传同一错误数据 |
| 历史较多找不到 | 页面只展示最近一批任务 | 不删除历史；通过只读接口／私有验收记录定位 |

练习完成停止自己创建的订阅，下载需要的产物，再运行 `.venv/bin/python stop.py`。它保留基础容器和数据。不要在日常操作中运行清库、重置配额或历史云端批次执行命令。

下一步：[当前实现架构](../engineering/architecture-current.md) → [代码阅读路线](../engineering/code-walkthrough.md) → [接口与排错](../engineering/api-and-debugging.md)。

## 14. 新增操作如何串起来

先新建练习空间，导入改名后的 v7 和 v1，完成本地结构解析，再检查正文候选和版本差异。进入发现页，选择两篇建索引：页面会逐篇创建任务，避免两篇共用单任务次数限制；全部就绪后联合提问。离线验收结果始终标为模拟。

阅读器中展开“参考文献检索与身份核对”。先选择参考条目，修改公开检索词，按标题、作者和年份核对结果。有开放 PDF 才能导入；再选择对应本地作品，填写核对依据并保存。图谱重新计算时采用最近确认，旧审阅记录保留。

图谱页的“后续论文全文证据对照”需要两篇已解析文献。分别选择原研究和后续研究的页码、段落，填写要核对的主张、判断及比较依据。下载的 JSON 包含两段原文和固定定位。这是人工有据核对，并未自动证明研究方向的新颖性。

任务展开后有“实时任务步骤”，可看到排队、领取、翻译分批保存和完成事件。断线按游标恢复；页面显示的是任务步骤，尚不提供模型逐 Token 输出。

## 15. 如何确认自己真正走通了

运行 `verify_completion.py`，顶部可修改资料路径与测试空间名称。脚本在独立空间使用真实 PDF 和模拟模型检查 7 个环节，报告在 `var/reports/feature-completion.json`。它不会覆盖已验扫描件的真实索引，也不会增加云端推理。

检查产物时先看来源，再看结论：回答里的引用是否支持该句，翻译是否改变否定范围，图表的列名和单位是否正确，论文框架是否把实验计划写成已完成。通过软件测试后仍需做这些内容检查。

## 图内文字与架构关系

在结构化原文阅读器中，带有原始图片的图块下方有“识别图内文字与结构”。提交后可查看图片中的可见文字、节点及连线。任务采用 `model_config.py` 的 `FIGURE_MODEL`，调用范围与额度需要已配置的云端策略。

展开“对照节点位置”，选择节点，可在原图上显示它的预测位置框。逐项检查重复模块是否分别保留、箭头是否反向、跨区域连接是否遗漏。方向不确定的连线显示 `?`。

发现错误时，展开“修订图内识别结果”，修改 JSON 中的节点文字、坐标与连线，填写依据并保存为新版本。坐标是相对图片宽高的 0–1 数值；每条连线的 source/target 必须对应已有节点 ID。保存不调用模型，原始识别结果仍可下载。

“记录原图核验”用于保存确认或错误标记。任务完成表示返回和保存过程结束；内容核验是独立记录。未核对的结构应结合原图阅读，不作为已经验证的科研结论。


## 2026-11-18：连贯工作空间

首页 → 文献库 → 选择文献 → 开始阅读。原件、证据问答与翻译共用当前文献；图谱与写作也可沿用来源范围。切换研究空间会清空旧范围，避免把上一个课题混进新问题。浏览器返回与刷新可以恢复页面、文献和历史结果位置。

结构原文的段落中可以用鼠标选择文字，再点“翻译所选文字”；页面携带精确源块和 Unicode 位置进入翻译，不会自动发送。不能与原文字面内容一致匹配的跨块/公式选择不会作为有效片段提交。原有可键盘选词的文本框仍保留。

“成果”按问答、译文、摘要与写作、图表、准备任务分类，读取当前空间最近 30 条工作室和 20 条问答/索引历史。打开结果会保留任务 ID 和可解析到的来源版本；译文会打开对应历史修订。下载保留原有文件/版本与来源清单，不会重新生成。

图谱页新增“整理图谱文献综述”，来源严格对应所选图谱作品中当前可取得的解析版本；缺少结构的作品不进入生成，提交前显示覆盖数量。没有新云端准入时只回看历史。图谱中的候选关系和审阅记录仍保留。

配置可用、任务完成和科学内容正确是三个不同状态。本次改版没有开放新的模型、OCR 或全文上传额度。软件已覆盖六模块入口，不等于所有官方科学质量样本都已通过。
