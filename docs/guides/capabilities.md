# 能力与验证范围

功能存在、任务完成和科研内容正确是不同的检查。页面为模型译文、草稿、模拟数据和候选引用保留标记，使用者需要根据来源判断结果。

| 能力 | 当前验证范围 | 仍需完善 |
|---|---|---|
| 文献解析 | 实际论文文本层、扫描 OCR 修订、长教材页级处理 | 复杂阅读顺序、全部公式/表格语义、扫描副本自动消歧 |
| 证据问答 | 固定单篇样本的来源核对，混合检索与确定性数值工具 | 跨论文和多轮真实质量集、冲突处理覆盖 |
| 翻译 | 全文分片、字面量保护、部分回执恢复和内容块对应 | 已观察到否定范围误译，仍需专业术语与语义审阅 |
| 写作 | 有来源草稿、缓存笔记、本地编辑派生与不可变版本 | 来源位置正确不等于每条论断均被来源支持 |
| 检索推荐 | 公开元数据适配、调度、反馈和代码链接状态 | 真实下载旅程、长期推荐效果和后续全文证据 |
| 引用图谱 | 实际本地文献集与可重算局域排名 | 候选目标身份核验；排名不能解释为全领域影响力 |
| 绘图拓扑 | 受控模板、数据/配置/脚本导出、明确第三维 | 输入数据质量仍由使用者负责；不执行任意模型代码 |
| 部署 | 本地启动、容器业务、会话/任务持久化与事件检查 | 公网、全新异构环境与生产备份恢复 |

本地 Ollama/MinerU 服务需要独立安装与验证。外部调用默认关闭，没有承诺可持续使用的免费服务或无限额度。Token 流式显示、科研长任务取消仍待完善。

测试运行通过 `validate.py` 输出独立报告。固定样本与合成契约测试不作为一般准确率；已有报告不自动证明之后的改动已经重新验证。原始数据和私有模型回执不随源码分发，依赖开发机样本的脚本不能当作新克隆通用检查。
