# 从第一篇 PDF 到研究成果

这份教程按实际使用顺序介绍 ScholarShip。先走通一篇论文，再使用多篇问答、文献发现和图谱。对应的[90 秒高清功能演示](../assets/demo.mp4)来自真实页面操作，按顺序展示各功能，已剪去全部等待与调试片段；[字幕](../assets/demo.srt)和[章节时间](../assets/demo-chapters.json)可单独下载。

## 先分清四件事

| 对象 | 什么时候得到 | 后续用途 |
|---|---|---|
| PDF 原件 | 导入到文献库后 | 保留原排版、翻页、核对来源 |
| 解析修订 | 提取文本结构，或发布获准的 OCR 结果后 | 阅读段落、定位图表公式、翻译与写作取材 |
| 检索索引 | 对已解析文献建立索引后 | 为证据问答检索候选段落 |
| 研究产物 | 问答、翻译、写作或绘图任务完成后 | 在成果页回看、核对、下载与修订 |

因此，**导入 PDF 后可以读原件，但不能立即向全文提问**。问答需要解析和索引；翻译与来源写作需要解析，CSV 绘图可独立使用。状态就绪说明该处理步骤完成，内容仍需核对。

## 1. 启动并登录

先启动 Docker Desktop。已有环境在项目目录运行：

```bash
.venv/bin/python dev.py
```

打开 <http://127.0.0.1:15173>，账号为 `researcher`，密码取自本地 `.env` 的 `INITIAL_USER_PASSWORD`。若页面已经运行，直接打开，不要再启动一套 Worker 或 Beat。

首次克隆需要先按照[安装指南](getting-started.md)配置 `bootstrap.py` 顶部的 Python 路径，运行 `python3.12 bootstrap.py`。不要用空模板覆盖已有 `.env`。新克隆不包含开发者的文献、成果或模型额度。

## 2. 为课题创建研究空间

点击页顶“新建空间”，填写名称并“创建并进入”。以后先看页顶的空间，再导入或查找文献；不同空间的资料、任务与成果分开。

演示中新建了“入门演示 · 从论文到成果”，后续新任务均在这个独立空间完成。新空间默认使用 mock 模型配置，适合熟悉流程，不会自动调用云端。

## 3. 导入 PDF 并检查原件

进入“文献库”→“导入 PDF”，选一篇有权处理的文本型论文。等待导入结果，在文献卡片中选择论文，确认页数、首页与文件版本，再点击“开始阅读”。

演示使用已在本机的 *Attention Is All You Need* PDF（15 页），没有向 OCR 或模型供应商上传。自动标题不合适时，可展开“文献整理、版本比较与归档”修改显示标题。

相同文件再次导入会复用版本。只有确认是同一作品的新版本时，才勾选“将下次导入明确作为当前作品的新文件版本”；不要把另一篇论文附加成当前作品的版本。

## 4. 查看自动处理进度

导入后系统默认在后台自动解析/OCR、切片、向量化和校验索引，并排队本地图内识别与中文翻译。文献库和阅读页均显示实际进度，离开或刷新页面后任务仍继续。完成后保存新的解析修订，原件和旧修订保留；也可在“本地解析与中英对应”逐页核对或手动更新。

至少核对首页、一个中间页面和末页，以及章节、公式、表格的对应关系。新版对低文本或乱码页调用已安装的 Tesseract，保留坐标与置信度；图表与阅读顺序仍需核对。未翻译内容明确标记，旧的本地文本层修订不会被改写。详见[本地文档处理](../models/local-document-pipeline.md)。

## 5. 与 AI 对话、追问与核对原文

在阅读页点击文献选择框旁的“与 AI 对话”，或切换同名标签。入口始终可见，准备进度直接显示在对话区。

1. 确认来源栏中的论文；需要多篇对比时，展开“问答来源与索引”调整，一次最多 8 个版本。
2. 在“执行方式”确认使用本地模型、离线验收或云端模式。可用性由模型服务、索引配置和授权共同决定。
3. 新导入文件会自动准备索引，对话区显示当前步骤；旧文献尚未准备时点“继续自动准备”，完成后即可发送问题。
4. 在始终可见的输入框输入具体问题，例如“本文的实验设置和评价指标是什么？”，点击“发送问题”。Enter 发送，Shift+Enter 换行。
5. 回答会直接出现在对话记录中；点击“引用 1 · 原件第 … 页”打开证据原文。检查出处是否支持回答，不只检查引用是否存在。
6. 在同一输入框继续追问，系统沿用本次对话的文献和索引范围。点击“新建对话”开始新的上下文，旧对话仍可在“当前来源的会话历史”中打开；刷新也可恢复当前对话。

解析操作收在“阅读与解析”中，不会挡住对话区。切换来源或执行方式后，历史会按对应范围展示，避免不同资料的上下文混用。“成果”页也可回看问答与来源。

**演示中新建的索引和问答采用模拟响应。** 它们展示软件流程和引用定位，不是模型对新论文的科学质量验证。当前开发环境的真实调用策略已关闭，不要把模型 Key 或配置组当作新的执行授权，也不要在已有真实索引的空间重建模拟索引。

视频另切换到“默认研究项目”，只读展示已完成的真实样本：8 个 NVIDIA P100 GPU 的回答及原件第 7 页高亮。它来自历史固定样本；切换空间已在字幕中说明。

## 6. 翻译与双语阅读

在“阅读与问答”选择一篇已解析文献，切换“选词与双语翻译”：

- 选目标语言；按需要选择整篇，或展开“选择页面与段落翻译”，勾选具体段落。
- 也可以在支持的原文框或结构原文中选中文字，再提交选段翻译。
- 任务完成后展开“阅读翻译”，点击“打开中英逐块对照”，按需切换“双栏同步”。
- 在“译文核对与人工修订”中检查术语、数字和否定表达；修改并填写依据会保存新修订，原版本保留。这里也可下载双语 Markdown。

新建的模拟翻译会明确显示“模拟译文”，不会生成可靠中文。视频只读展示已有真实译文的双栏阅读与同步滚动，没有新增真实翻译请求。

## 7. 发现相关文献

“研究工具”→“打开文献发现”，选择 arXiv 或 Crossref，输入标题或主题并“检索公开文献”。这会向对应服务发送查询词，不发送本地 PDF，也不调用大模型。

逐项核对检索结果。Crossref 的元数据不等于可用全文；只有页面明确提供公开 PDF 下载入口时，才使用该入口。反馈用于记录兴趣；需要长期追踪再创建订阅，使用完可停止。

本次实测 arXiv 返回网络错误，Crossref 检索成功，视频展示 Crossref 的实测结果。相似标题可能指向不同论文，检索命中不能直接当作文献身份已确认。

## 8. 查看引用图谱与研究线索

“研究工具”→“打开引用图谱”，选择文献，点击“构建引用图谱”。图谱基于已有引用数据，本地计算，不需要模型。

只有一篇文献或没有已提取引用时，图可能没有边，这不代表操作失败。视频使用已有的 23 篇本地文献集，得到两条候选关系；虚线和候选标记保留，文献身份仍需核对。PageRank 只描述当前网络，不能解释为领域地位。

图谱来源综述与研究方向草稿需要模型执行条件；后续元数据检索和人工全文证据对照是不同操作。没有搜到后续论文，不能据此认定方向尚无人研究。

## 9. 整理摘要与写作框架

“研究工具”→“打开学术写作”，选择已解析来源，填写研究目标，例如“整理注意力机制的研究计划，区分原文结论与待验证假设，不编造实验结果”。再选择“生成带来源清单的框架”或“整理来源摘要”。

任务完成后检查各节、来源笔记与文献身份，下载“产物与来源清单”。这些内容是草稿，需要逐条核对；引用位置存在不等于每条主张都已被证明。视频中的新建框架使用模拟响应，并保留模拟标记。

## 10. 从 CSV 绘图并导出

准备 UTF-8 CSV，首行为字段名。可使用与视频一致的[页级字符数 CSV](../assets/demo/page-text-counts.csv)：它来自演示 PDF 的本地文本提取统计，不是模型性能或实验结果。

进入“研究工具”→“数据绘图”，按视频设置：

| 输入 | 值 |
|---|---|
| 图形 | 柱状图 |
| X / 名称列 | `page` |
| 数值列 | `text_chars` |
| 单位 JSON | `{"page":"PDF page","text_chars":"characters"}` |

点击“生成可复现图表”，完成后下载产物。ZIP 内有 `input.csv`、`chart.png`、`plot.py`、`metadata.json` 和 `README.txt`。在解压目录用本项目 Python 环境运行 `plot.py` 可重建图像；本次同环境复现的图片哈希与原图一致。

同一页面还可输入 `PDF 导入 → 本地解析 → 证据检索 → 回答生成 → 引用核对`，点击“按描述生成架构图”。它按明确节点和连线生成 Mermaid，不自动猜测未描述的系统结构。

## 11. 在成果页收尾

“成果”按问答、译文、摘要与写作、图表等分类。通过“打开结果与来源”继续核对，通过下载入口保存产物。页面回看不会重新生成模型结果。视频结尾展示本次独立空间中实际新增的任务与产物。

当前空间的数据保留在本机。需要结束本地应用时运行：

```bash
.venv/bin/python stop.py
```

它保留数据库、基础容器和文件。更详细的版本管理、翻译修订、任务取消与故障处理见[完整使用手册](user-manual.md)；真实模型的配置和准入见[模型指南](models.md)。
