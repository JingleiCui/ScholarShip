# AI 辅助开发披露

本项目由用户提出场景、技术偏好、预算和参赛范围，并逐阶段确认；Codex 辅助完成了大量设计与实现，包括脚手架、后端领域与模型适配、迁移、前端、自动化验收、问题诊断及文档。不能将 AI 贡献仅表述为少量润色。最终代码和科研输出仍需参赛者理解、复核并负责。

GPT Image 用于生成 UI 概念图，相关提示词见 ../design/；最终网页以 React/CSS 实现，不把生成图当作实际界面。ChatAnywhere/OpenRouter/MinerU 在已批准范围内参与样例生成、向量、重排和 OCR，真实回执与模拟结果分开，失败记录保留。

核心提示/政策在源代码中版本化：证据问答使用受限证据和精确引用菜单；翻译保留本地字面量并分片缓存；写作先生成有限来源笔记、再生成带来源的草稿；研究方向不得凭未检索到断言未解决；图表和拓扑走受控模板。相应代码见 backend/src/scholarship/domains/ 与 models/。真实 API 密钥、原始论文和私有完整模型回执不随仓库分发。

提交技术文档时应结合实际使用情况再次核对这份披露，不虚构人工工作量或科研效果。
