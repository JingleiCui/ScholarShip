## 本批实现

- 新增 `0007_bounded_live`：model_runtime.grants 授权表、calls 的授权关联和网络槽标记，以及窄权限准备/发送/停止/完成函数。原 41 张业务表不变，旧迁移未改写。
- 授权只可由显式的管理维护命令记录；普通应用角色不能创建、扩额、复活或重置授权。常规服务开关保持关闭，此次单独授权不开放一般科研问答或文件上传。
- 每次调用固定 provider、型号、角色、操作参数摘要和准确的 URL/JSON 请求摘要。发送前在 PG 原子提交计数与 sent 状态，最多 5 次，过期或关闭授权拒绝发送；重复成功意图重放回执，不重新发送。
- HTTP transport 不重试、不重定向、不使用环境代理或付费模型回退。真实凭据仅在发送前加入对应主机的头，不进入清单、日志和回执。
- 401/403/429/5xx、超时、坏回执、异常型号等停止授权；超时或不确定响应保留 unknown，后续不得盲目重发。兼容免费路由报告同名基础型号与已知 ChatAnywhere 日期别名，同时保留请求/报告型号。
- 命令入口 `validate_live_models.py` 默认 status，不发送网络。record-stop 是本次用户授权的显式审批维护操作，使用管理员连接写入已停止授权；status/run 使用 runtime 租户连接和本地非密钥引用，不加载管理员凭据。状态不 active 时 run 不发送请求。

脚本顶部 REQUESTS 完整列出原拟执行的五个合成请求：短聊天、两条文档向量、一条问题向量、两候选重排和合成证据 JSON 回答。全部是固定合成短文本，没有读取论文用于外发。
