# 模型配置与任务快照

所有服务目录和常规参数集中在根目录 `model_config.py`，凭据仅从私有 `.env` 读取。项目保存的模型选择优先于文件中的默认配置；修改默认值不会覆盖已有项目。

## 云端角色

| 用途 | 配置位置 | 接口 |
|---|---|---|
| 聊天、问答、摘要与翻译 | `PRESETS` 和项目角色覆盖 | Chat Completions |
| 向量化 | embedding 角色 | Embeddings |
| 重排 | rerank 角色 | Rerank |
| OCR / 深解析 | parser 角色 | MinerU 云端解析生命周期 |
| 图内识别 | `FIGURE_MODEL` | 图片输入与 JSON Schema 输出 |

`FIGURE_MODEL` 独立选择图片模型，只影响新建的图内识别任务，不改变项目日常问答模型或历史任务。`VISION_MODEL_BINDINGS` 声明允许的视觉型号，配置不会授予外部调用权限。

## 切换与扩展

同协议的新模型在 `MODELS` 中登记，并在 `MODEL_CAPABILITIES` 声明用途；同协议新平台扩展 `PROVIDER_DEFINITIONS` 的地址、凭据环境变量名和协议绑定。新协议在 `models/protocols.py` 注册，供应商差异不进入业务工作流。

新任务固定角色、型号、端点、协议版本与参数策略。历史快照保留自己的来源与配置；不将新模型参数悄悄套用到旧任务。聊天模型切换不要求重建向量索引；向量型号、维度或输入政策切换需要独立 profile，建立和验证候选索引后再切换活动世代。

## 运行与诊断

账户权限、模型选择、数据范围和用量准入分别校验。成功调用保留回执，未知结果保留占额；权限、限流与计费异常不自动转移到其他型号。调用策略详见[服务配置](../guides/models.md)。

`LIVE_PROXY_URLS` 仅用于明确配置的本地代理，关闭环境代理继承；`DOWNLOAD_DNS_OVERRIDES` 只影响对应下载请求，TLS 仍验证原始域名。移机应重新核对这些设置。
