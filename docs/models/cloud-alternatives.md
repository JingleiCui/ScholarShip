# 可选云端分工

本轮只做本地实测和官方文档查询，没有开通或调用以下云端候选。模型推荐是按任务和接口能力作出的判断，不是本项目已完成的云端速度或科学质量验收。

| 任务 | 当前建议 | 希望减少等待时的候选 |
|---|---|---|
| 向量化 | 保留本地 Qwen3-Embedding-0.6B；小样本实际 1024 维调用约 0.92–1.82 秒 | 暂无迁移动机；更换后必须独立 profile 并重建索引 |
| 重排 | 优先本地 Apple MPS、小批量；原 CPU 方案确实曾超时，失败记录保留 | 若后续机器缺少可用加速器，再独立评估云端 rerank API |
| 摘要、翻译与一般问答 | 本地已可执行；长输出仍会增加等待时间 | 官方 Qwen Flash 可作为成本优先的试验候选 |
| 跨文比较、较长草稿、图内识别 | 可先本地；图结构始终需要内容复核 | 官方 Qwen Plus 可作为质量优先的试验候选 |

[官方文本与视觉模型说明](https://www.alibabacloud.com/help/en/model-studio/text-generation-model)说明 Qwen Flash、Plus 的文本及视觉输入能力。具体版本、区域、输入长度和计费阶梯需按[官方价格表](https://www.alibabacloud.com/help/en/model-studio/model-pricing)核对，不能从“兼容 OpenAI”推断账户权限、速度或免费额度。

若选择候选，先登记提供商和模型能力，补对应响应格式/推理参数的离线契约验证，再单独确定资料范围、请求次数及预算。当前生产执行器保留既有免费策略和非零费用拒绝逻辑，付费结算需前向扩展；不能仅填入 Key 就宣称付费接口已接通。本轮没有替换已有云端型号、重开旧额度或上传资料。

本地测量基于特定小样本和当前机器，包含加载、排队或缓存差异，不能当作长文吞吐量保证。复杂图的 schema 有效性、坐标合法性和语义准确性分别记录，未审阅输出不会标成已验证科学证据。
