# 研究工作室的页面整理

受众为研究生和评审。首要工作是选研究空间、选来源、执行任务、回看原文与产物；保留已有 ScholarShip 视觉，不做品牌重建。

- 沿用纸面 #f6f7f3、正文 #263c37、证据绿 #286254、边界 #bdcfc5、键盘焦点 #c79753；颜色分别表达背景、信息、可操作项、分组和焦点。
- 沿用现有中文系统字体；正文 14px、局部标题 18–24px，行长以可读性为先。没有新增字体下载。
- 页顶固定显示空间选择；模块页只显示研究操作和结果，工作台保留环境与概览。
- 来源选择放在可滚动的紧凑区，提供全选/清空，图谱和方向来源分别明确。任务状态和错误改成可行动的中文说明。

```text
页顶：模块 / 研究空间 / 账号
来源：范围选择 + 批量操作
执行：输入与明确动作
结果：状态 / 限制 / 原文定位 / 产物
```

审视：不增加同类装饰卡、不改变既有配色；删去模块页重复的首页宣传与环境区，让来源、失败原因和研究结果形成实际层级。候选关系、模拟输出和已知错误仍显著标记。
