# 研究工作室实现边界

2026-11-16。开发范围由用户授权覆盖其余比赛模块；外部调用仍单独受来源与批次约束。沿用架构和 41 张业务表，不把每个工具扩成独立服务。

## 可插拔执行

业务调用统一 gateway 能力端口，提供商目录、协议转换、HTTP、准入结算各有边界。`model_config.py` 定义配置组与可编辑参数，密钥仅从私有环境读取；新任务冻结 models-v2 绑定。换聊天/翻译模型影响新任务，换 embedding 必须使用独立 profile 和索引世代，通过验证才切活动指针，不能截断原生维度或混用合成向量。

`research_studio` 是持久任务类型，operation 分别为翻译、摘要、框架、研究方向、后续证据检索、已有产物整理、图表、拓扑和本地结构解析。Celery 执行，PostgreSQL run/outbox/租约是依据；模型工具固定政策版本，失败显式停批，已知结果与 unknown 分开，恢复由新授权和缓存证据决定。0011 扩展投递，0012 加强指定解析来源的生产准入，0013 提供受限部署文件清单；不改已部署迁移。

## 来源与产物

源文件 → 不可变解析修订 → 页面/块/表格/引用 → profile 与 generation → 检索/重排 → 引文菜单 → 精确块位置。作者顺序及数值比较可使用确定性结构工具；算法与模型来源在结果中标明。旧回答的科学错误通过追加审阅记录警告，不改原回执。

翻译把公式、代码、邮箱及 HTML 等字面量留在本地，模型仅接收普通文本片段；每片独立缓存并保留请求来源，合法部分先保存，缺项暂停。v2/v3/v4 提示与策略分别冻结。双语阅读以块为单位组装和同步，不把一张表拆成无效 HTML。

写作先按 2,500 UTF-8 字节生成简短来源笔记，再在 6,000 字节预算内生成摘要/框架，复用缓存。引文来源窗口映射为精确 Unicode 块范围；位置正确不等于语义支持。已有草稿可本地整理成新不可变版本，原输出保留；书目从扫描首页提取时明确为自报告，外部身份未验证。

## 其余模块

- 检索：固定 arXiv/Crossref HTTPS 主机、响应大小与页数上限，arXiv 共享节流与缓存；只从指定 arXiv 路径下载开放 PDF。元数据与全文状态分开。反馈推荐为可解释本地打分；GitHub 仓库存在、许可与复现状态分别记录。
- 图谱：选中论文的显式标识/已验证引用，NetworkX 有向图及可重算 PageRank。无边保留无边；候选目标身份未复核用虚线，不把同主题相似度当引用。
- 研究方向：保存检索词、时间、元数据证据与原文 Future Work 候选；没有找到后续全文证据时禁止宣称问题未解决。
- 绘图：CSV 有限大小、有限数值、缺失值政策和单位；雷达图记录归一化边界，三维雷达必须指定实际第三列。PNG/CSV/metadata/脚本打包，模板执行，不执行模型任意 Python。中文字体显式选择并写入配置。
- 拓扑：结构化节点/边或箭头文本编译为 Mermaid，严格渲染，不执行模型任意脚本，下载源码。

## 页面与安全

保留现有视觉，研究空间移至页顶；模块按需读取数据，来源选择可折叠并批量选择。表格以白名单 React 元素渲染，KaTeX trust=false，Mermaid strict；没有直接插入不可信 HTML。原文、翻译和导出均沿用 owner/project 范围检查，文件哈希读取验证。

云端权限不是模型配置的一部分。准入同时核验总开关、角色、配置、已证明 profile、owner/project/parse 范围、期限与配额。完成批次关闭策略并封存剩余名额。普通文件完整性检查使用固定 runtime 只读清单函数，不能读取管理员密码。
