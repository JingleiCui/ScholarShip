## 发现和修复

- 作者检索可能只看到另一位作者；现按页面作者结构顺序提取并带脚注。旧错答仍显示审阅警告。
- 模型带真实引用仍可能选错表格基准；现解析 rowspan/colspan 并按目标列和基准范围比较，用 Decimal 计算。没有把引用存在当准确性保证。
- 供应商精简 JSON 仅在能无歧义恢复时兼容，未知引用仍拒绝；原 unknown 不改写。
- 翻译保护标记或批次缺项会停批。改为字面量留本地、短 ID、小批次、合格部分持久化；历史回执恢复核对原请求哈希和源文，不重发已经成功的片段。
- 写作上下文按 UTF-8 大小分窗并缓存来源笔记。原摘要生成了不必要章节，新增明确的本地编辑派生，保留原稿。
- 本地 PDF 的 NUL 字符替换为可见的 � 并记录数量，不能伪装识别成功。逐页释放解析缓存。
- 部署预检原先读取管理员配置，已用新增 0013 的固定 runtime 清单函数替换；最终 165 个已登记文件大小/哈希通过。初始及已部署迁移未改。
- 容器依赖下载并发过高引起网络超时，降低到 4 并保留缓存；一次并行验收受到基础服务超时影响，重跑通过。调度器被 192 MB 内存上限终止，增加到 384 MB 后任务与事件检查通过，重启计数为 0。

## 质量与提交限制
