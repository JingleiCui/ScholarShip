## 已确认的设计决策

| 决策 | 本轮提案 |
|---|---|
| 存储职责 | PG 为业务事实，Qdrant 可重建，Redis 仅队列；文件不可变并校验 |
| 版本模型 | 作品/文件载体/解析/结构块/索引世代/翻译/产物分别标识，历史不静默改指向 |
| 隔离 | owner/project 复合外键、服务端范围过滤与 RLS；官方 checkpoint 独立 schema 并做归属校验 |
| 结构规模 | 41 张业务表；作者等变动信息用版本化 JSONB，图谱和报告复用产物体系 |
| 向量初值 | 百炼 text-embedding-v4、1,024 维、Cosine、每项目每 profile collection、原生全文 BM25 + RRF + 重排 |
| 检索映射 | chunk 及原文 span 保留 PG；600/900/80 token 初值；关键数据从原文核验 |
| 一致性 | outbox、租约 token、确定 point ID、构建核验后切活动指针；未知外部调用先对账 |
| 费用 | 原子预算预留 + 追加账本；估价和供应商账单核对分开；具体额度/周期后续确认 |
| 删除恢复 | 普通操作先软删除并阻断访问；精确范围异步清理；原件/产物不默认自动过期；备份需恢复演练 |
