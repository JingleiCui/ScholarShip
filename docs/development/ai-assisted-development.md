# AI 辅助开发

ScholarShip 使用 Codex 辅助设计和实现，覆盖脚手架、后端领域逻辑、模型协议、迁移、前端、测试自动化、诊断和文档。项目方向、数据范围与执行条件由维护者决定；提交代码和使用科研结果的人仍需理解、审查并负责。

GPT Image 用于 UI 概念探索，提示词和历史方案保存在 docs/design/。实际网页使用 React/CSS 实现，概念图不是运行截图。第三方模型参与生成、向量、重排与 OCR 时，真实来源、模拟输出和失败状态分别记录。

核心提示与政策随代码版本化：证据问答限制来源与引用菜单；翻译保留本地字面量并缓存片段；写作先汇总来源笔记再生成草稿；后续检索不以未找到证明未解决；图表和拓扑使用受控模板。相关实现位于 backend/src/scholarship/domains/ 和 models/。

提交问题或改进时，请说明 AI 辅助部分和实际验证方式。不要因为代码能运行就认定科研结论正确，也不要在公开报告中提交密钥、私有文档或完整敏感回执。
