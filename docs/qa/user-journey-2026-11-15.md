## 已修复问题

1. 重复导入缺少成功反馈；同一文件再次选择可能不触发 change。现在清理文件选择值、显示复用提示，并在新版本导入后自动选中文献。同版本重复导入保留用户当前修订选择。
2. 文献库没有解析修订选择，且已有 OCR 仍被总文案误报为未解析。现在支持本地预览/OCR 修订选择，接入已有结构化阅读器；减少每轮轮询造成的重复文本加载。
3. 切换 embedding 后只能提交再报错。新增与后台同一规则的索引就绪检查，在提交之前提示重建；地址、模型、维度、协议、模拟位参与匹配，后台仍独立校验。
4. 原始 JSON、英文内部错误直接出现在界面。文献库/研究面板/阅读器共用脱敏中文错误处理，不展示原始代理响应。
5. 原文画布只适应宽度，窄屏不可读。增加 100%/150%/200% 缩放、滚动、上一页/下一页、返回引文页。
6. 刷新后模块回到工作台。以非敏感 URL hash 保存模块位置；未实现的模块增加明确提示。
7. 本机 API/worker/Beat/前端存在失去启动器的旧进程，新启动因端口占用退出。核对 PID、PPID=1、命令签名及本项目 cwd 后，对 4 个已确认进程发送 SIGTERM；未使用模糊 pkill，未处理其他项目。随后通过重启验收并恢复受管理启动器。此项是环境恢复，不声称已实现任意 SIGKILL 下的自动孤儿回收。
