# M1 文献导入与本地预览验收

日期：2026-11-13。用户已确认 M1 范围。已实现文献导入、文件复用、候选去重确认、显式追加文件版本、逐页预览解析、进度与失败恢复，以及 PDF.js 原文页码导航。本批未调用付费 API。

## 已交付

- 按账号/项目授权的流式上传、SHA-256、随机暂存文件和原子发布；上限 128 MiB / 2,000 页可在代码配置区修改。PDF 验证放在独立子进程，30 秒超时回收；损坏、加密、非 PDF 和超限文件拒绝导入。
- 同账号相同字节复用文件；同项目相同载体不重复建版本。同一幂等键配不同字节返回 409。上传回执及状态接口可追踪已提交资源。
- 作品与文件载体分离。选择当前作品并勾选“作为新文件版本”后，才将不同载体归到同一作品；不依靠相似标题自动合并。标题及 DOI/arXiv 候选进入人工核验，可保留两份独立记录或拒绝新增记录，决定追加审计。标识提取只是候选，不代表出版社真实性核验。
- 新增 Alembic `0002_documents`，扩展受限 outbox 领取函数，41 张业务表结构不变。没有修改初始迁移快照。
- PDF 任务通过真实 Celery/outbox 执行，逐页提交并刷新租约。进程级数据库锁阻止同一任务并发改页；恢复跳过已完成页，保留页/块 ID。最多 3 次执行尝试，失败可显式继续未完成页，重新解析则创建新修订。
- PDF.js 展示授权原件，页码切换同时读取同一解析修订对应的页级文本与原文锚点；文本块携带内容哈希和实际页号。页面显示进度、解析修订、诊断和文本层缺失提示。
- 自动化入口 `evaluate_m1.py` 检查三份真实材料；`recover_m1.py` 在明确识别本项目启动器与 worker 后，验证真实教材中断恢复。常用配置位于文件顶部，沿用用户代码配置偏好。

教材另做真实 worker 强制终止测试：恢复到全部 **541 页**，约 **84.27 秒**（含重启、租约过期等待与余页处理），第 1 页 ID 保持不变，没有重复创建已完成页。浏览器已核对第 1 页与第 541 页的 PDF 图像和文本对应；PDF 文件页码 541 对应书内印刷页码 527，界面以 PDF 文件页码为准。

## 自动检查

基础与 M1 集成测试共 **20 项通过**，覆盖上传、版本追加、加密/损坏/超限拒绝、账号隔离、候选去重决定、标识标准化、原件丢失失败与显式恢复，以及真实 worker 强制终止后的已完成页复用。原有 RLS、约束、BM25、checkpoint、SSE 等基础检查保留。前端类型检查、生产构建、Ruff 和敏感值扫描通过。最终脱敏机器结果见 [M1 证据](evidence/m1.json)。

测试文件改用唯一 `var/tests/ss_test_<uuid>` 目录，worker 与 API 共用相应测试配置，测试结束只清理该目录与对应临时数据库。原始比赛资料、业务文件和其他项目服务不在清理范围。

## 边界

这是**本地页级预览**：双栏阅读顺序、公式和表格结构尚未核验，不能作为深解析质量或证据问答验收结果。预览不会自动切换 active 深解析/索引指针。正文双语翻译、OCR、MinerU、真实向量与重排、问答仍未启用。

DOI/arXiv 来源为文件名及首段文本的本地候选提取，没有外部检索核实；历史调试导入记录保留原始元数据，不回写旧版本。相似题名的复杂实体合并与撤销尚未实现，当前提供明确的文件版本追加及保留/拒绝操作。

本轮验收针对本机模式；M0 容器镜像的历史验收不代表新 M1 镜像已验收。容器模式使用独立文件卷，当前业务原件在本机 `var/files`，切换前须显式同步文件并重建镜像，不能只复用业务数据库。公网部署仍待后续阶段处理。
