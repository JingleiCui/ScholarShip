# 下一增量评审：M2 正式业务闭环

当前真实小样本与扫描 OCR 的结果见 [联调报告](../models/live-official-report.md)，比赛完整差距见 [审计](../competition/audit-2026-11-14.md)。本单是具体实施范围，不表示已实现或已批准新的模型名额。

## 拟交付

1. **真实 MinerU 产物入库**：复用已下载的唯一扫描件结果，适配 3.4.4 layout/content_list；建立页面、标题层级、文本/公式/表格、References 和图片资产的版本化映射。验证页序、阅读顺序、CropBox/旋转及 native bbox 到 PDF 坐标变换，原始 JSON 与哈希保留，异常结构不发布。
2. **真实向量 profile 与索引**：增加严格核验真实成功回执的登记函数/迁移，不放宽历史的合成限定；维度、角色、模型/协议/输入策略、owner/project 及 parse 修订都参与约束。新世代验证完再切指针，失败保留旧活动索引。
3. **真实问答产品入口**：将可插拔 gateway 接入后台任务、会话和前端；按源版本保存 claims/evidence，引用能跳到真实 PDF 同一修订。把当前独立的 OCR 与短片段验证连成正式文献业务链路。
4. **可持续准入**：生产调用单独接入统一预算、免费请求上限、用量/unknown 与缓存；不通过扩大一次性验证的 5 请求/256 Token 限制来伪装成生产执行器。不静默自动切供应商。
5. **验收**：标准、扫描、长教材分区的接口/存储测试；真实原文定位和重启恢复；题集分离，逐项记录官方五问、多文四问及拒答/冲突。教材分区要验收后才考虑上传，不在此自动增加文件授权。

## 开发与调用边界

本增量可以先复用本地真实产物和合成供应商响应开发，不需要充值、新 Key 或新的论文上传。当前 12 个模型名额和唯一扫描件名额均已结束；新增云端用量、其他文件上传及正式服务启用应在可评审清单中单独确定。本单不授权购买服务器或发布公网。

完成后再分别进入阅读翻译、自动检索推荐、图谱/研究方向核验、写作/受控绘图和交付部署评审，覆盖全部 A01–A25。
