# M2 离线适配验收报告

后续进度：离线深解析/索引/问答业务链路已另批完成，见[业务验收](business-report.md)。本文件保留上一批的验收时点。

2026-11-13。用户已确认离线适配开发；本批完成 MinerU、向量、重排和文本问答的合成接口契约、数据库统一预算准入及工作台只读状态展示。**未启用真实文件上传、模型请求或科研问答业务链路。**

## 已实现

- `OfflineWire` 只接受 `httpx.MockTransport`，拒绝真实 HTTP transport；关闭自动重试和重定向。四类适配检查端点、批量、输出长度、响应形状和有限数值；异常不会记录原始密钥、供应商正文或签名链接。
- 向量采用 1,024 维与精确索引集合检查；重排检查候选索引、重复项和得分。问答验证证据 ID、Unicode 子串区间、引文文本和可信页码，拒绝工具调用、截断及伪造引用；无证据返回不足说明。**精确引文校验不证明答案语义和数值正确。**
- MinerU 覆盖批量申请、无 Bearer 的签名上传、批次轮询、安全结果下载和内存 ZIP 检查。拒绝路径穿越、符号链接、重复路径及压缩炸弹，明确零基页码转 PDF 一基页码。上述请求仅发送给测试桩。
- 原 41 张 `scholar` 业务表保持；新增 `billing.pools`、`billing.allocations` 两张平台账务表。迁移头为 `0004_billing_guards`，已部署迁移保持冻结。详见[账务设计](billing-design.md)。
- 离线执行器将调用意图、摘要、预留和审计同事务写入；成功结果重放不再次请求，提交结果未知不自动重发。报价绑定模型、操作、端点及契约版本；文本输出按实际请求的 2,048 Token 上限预留。
- 登录后的工作台显示本地共享预算、支出、占用和本人未知调用数量。只读接口为 `GET /api/v1/system/external-services`；不会查询供应商余额，未提供真实问答调用入口。

## 验证结果

[机器验收摘要](../evidence/m2-offline.json)：完整 `validate.py` **61 项测试通过，17.974 秒**；frozen 依赖、Ruff、TypeScript/前端生产构建、PG/Qdrant/Redis 健康、敏感值扫描全部通过。

其中新增 41 项覆盖离线请求/响应契约、恶意结果包、并发共享额度、租户/角色隔离、直接写账拒绝、幂等冲突、未知占额、未发送释放、超额阻断、过期阻断、回执丢失及重放。其余 20 项保留 M0/M1 回归，包括本地 PDF 预览恢复。测试使用唯一临时数据库、独立队列及向量集合；没有将合成使用量记入业务共享池。

本机 HTTP/进程恢复检查通过：会话保留、排队任务跨重启完成、收到 3 条探针事件。工作台已实际检查；[截图](../../var/reports/m2-budget.png)位于本机忽略目录。业务池显示 100 CNY 上限、支出 0、预留 0、真实调用关闭。这是本地预算配置，**不是供应商账户余额或赠送额度**。

## 明确未验收

- MinerU 检查器目前只接受公开的 `docvortex.middle` 2.0 结构并保留原始 JSON、哈希和页映射；实际云端版本未核实。结果始终 `publishable=False`，未发布为标准化深解析版本。不能以 ZIP 检查通过宣称 OCR、表格或公式正确。
- 尚无深解析业务入库、分块/profile 定稿、Qdrant 索引世代发布、完整检索/LangGraph 问答链路和研究效果验收。query/document 非对称参数、供应商 tokenizer 与输入额度估算需在索引阶段定稿。
- 凭据、模型权限、实际余额、MinerU 费用/权益及数据保留删除规则仍待核实。5 元首批联调只是提案，未启用；没有购买或充值。即使修改外部开关，当前也没有真实 HTTP transport 工厂可供执行。
- 本批未重新构建或验证应用容器；本机与容器文件卷仍分离，切换前需解决存储一致性。未发布公网服务。
